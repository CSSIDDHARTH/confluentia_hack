Fonts served by the app (app/static/fonts), so it looks the same offline.
- Google Sans Flex (Regular, Medium, Bold) and Google Sans Code (Regular, Medium), by Google, SIL Open Font License 1.1,
  from Google Fonts (fonts.google.com/specimen/Google+Sans+Flex, /Google+Sans+Code). Also used to draw the tags on photos.
- Material Symbols Rounded, by Google, Apache License 2.0, from Google Fonts, cut down to the icons the app uses.
- Roboto (Regular, Medium, Bold), by Google, Apache License 2.0: the previous app font, kept as a fallback for photo tags.
